cfd_zoner.py — zonal analysis of M-Star CFD volume (VTI) output

See methodology.md for how zones are created and how to interpret the results.

Expected case layout (M-Star native results directory):
    case/input.xml
    case/*.stl
    case/out/Stats/*.txt
    case/out/Output/Volume.pvd
    case/out/Output/Volume/block0/*.vti
    case/zoner_output/            (created by the tool)

Examples
--------
python cfd_zoner.py <case_dir> --variable edr --n-zones 4   # fixed zone count
python cfd_zoner.py <case_dir> --variable shear             # auto zone count
python cfd_zoner.py <case_dir> --variable edr --time 8      # manual time point
python cfd_zoner.py <case_dir> --variable edr shear tke     # several variables
python cfd_zoner.py <case_dir> --list-vars                  # show available arrays
python cfd_zoner.py <case_dir> --html --no-plots            # interactive 3D HTML only
python cfd_zoner.py <case_dir> --log-bins                   # order-of-magnitude zones
python cfd_zoner.py <case_dir> --log-bins --log-base 2      # zones per doubling
python cfd_zoner.py <root_dir> --batch --n-zones 4          # all cases + comparison

Positional argument
-------------------
case                      M-Star case directory (or a single .vti file);
                          with --batch, a root directory whose subdirectories
                          are cases

Options
-------
-h, --help                show help message and exit
--batch                   process every case subdirectory under 'case', then
                          compare zones across cases (rank-aligned: impeller vs
                          impeller, class 1 vs class 1, ...)
--variable VAR [VAR ...]  variable(s) to analyze, fuzzy match (default: edr)
                          aliases: edr, tke, velocity, shear, tracer,
                          kolmogorov, micromixing
--n-zones N               total zones incl. impeller; omit for automatic
                          selection via silhouette score (default: auto)
--time T                  analysis time [s]; overrides steady-state detection
--steady-on {variable,power}
                          steady-state criterion source (default: variable)
--tol TOL                 steady-state tolerance on windowed-mean drift
                          (default: 0.02)
--window W                steady-state window [s] (default: 1.0)
--instantaneous           use instantaneous field even if a Time-Avg variant
                          exists (default: use Time-Avg when available)
--linear                  cluster on linear values instead of log-transformed
--log-base {2,10}         log basis for zoning (default: 10). With the default
                          k-means zoning this is cosmetic (k-means is scale-
                          invariant, log2 and log10 give identical zones); it
                          matters with --log-bins
--log-bins                zone by fixed 1-log-unit bins instead of k-means:
                          class boundaries at powers of the base, i.e. orders
                          of magnitude (10^k) with --log-base 10 or doublings
                          (2^k) with --log-base 2. The zone count follows the
                          data range (--n-zones is ignored); log2 gives ~3.3x
                          more zones than log10
--min-zone-frac F         min sub-zone size as fraction of fluid volume;
                          smaller fragments are merged (default: 0.005)
--eta2-threshold T        between-zone variance fraction (eta^2) above which
                          gradients are flagged significant (default: 0.5)
--contrast-threshold T    zone contrast (max/min zone mean) above which
                          gradients are flagged significant (default: 3.0)
--impeller-pad P          impeller cylinder padding fraction (default: 0.15)
--impeller-percentile P   velocity percentile for fallback impeller detection
                          when no impeller STL/axis is available (default: 99.0)
--impeller-shape {cylinder,blob}
                          fallback impeller zone shape (default: cylinder)
--no-impeller-zone        skip the geometric impeller zone; all n_zones come
                          from clustering
--output-dir DIR          output directory (default: <case>/zoner_output;
                          in batch mode, per-case subdirs are created under it)
--list-vars               list VTI arrays and exit
--no-plots                skip diagnostic plots
--no-render               skip 3D rendering
--show                    open interactive 3D window
--html                    export interactive 3D HTML (zones_3d.html) and a
                          binary glTF model (zones_3d.glb) for PowerPoint

Outputs (written to the output directory)
-----------------------------------------
zones.csv                 per-zone and per-sub-zone statistics
heterogeneity.csv         local-vs-global significance metrics (see below)
zones.vti                 labeled grid (ZoneClass, ZoneID) for ParaView
time_trace.png            stats trace with steady-state and analysis markers
histogram.png             value distribution with class boundaries and means
exposure_cdf.png          cumulative fluid volume vs. value ("what fraction of
                          the batch sees <= X?") with global/zone mean markers
profiles.png              volume-averaged axial and radial profiles
zone_weights.png          zone volume fractions vs. contribution to the mean
zone_slice*.png           zone maps (side, side2, top views)
zone_pct_slice*.png       zone mean as % of global mean (same views)
zones_3d.png / .html      3D rendering (cutaway) of the zones
zones_3d.glb              3D model (insert into PowerPoint via Insert > 3D Models)

With several variables, each variable writes to zoner_output/<variable>/.

Batch outputs (written to <root>/zoner_comparison/)
---------------------------------------------------
comparison.csv            case x zone stats with case global mean and
                          zone-mean / global-mean ratio
heterogeneity_by_case.csv all heterogeneity metrics per case
heterogeneity.png         eta^2, CV, zone contrast, gradient index by case
zone_means.png            absolute zone means by case (log scale)
zone_ratios.png           zone mean / case global mean (1.0 = case average)
zone_volfrac.png          zone volume fractions by case
global_means.png          case global fluid means
zones_2d.html             2D zone maps, one subplot per case (self-contained,
                          per-case rank colors)
zones_2d_common.html      2D zone maps on one shared discrete color scale:
                          zones with the same mean get the same color, so
                          differences across cases are directly visible
zones_2d_normalized.html  2D maps of zone means on a continuous (log) color
                          scale spanning the lowest..highest zone mean across
                          all cases
exposure_cdf.png          combined volume-exposure curves of all cases
                          (dashed lines: case global means)
zones_3d.html             interactive 3D zone views, one subplot per case
                          (linked cameras: rotate one, all follow)

Zones are clustered per case; the comparison aligns them by rank
(class 1 = highest values in each case). Pass --n-zones in batch mode so
every case has the same zone count.

Zoning methods
--------------
Default (k-means)         classes found by k-means on log10 values: boundaries
                          fall wherever the data naturally clusters (variable
                          width in log space); zone count from --n-zones or
                          silhouette auto-selection.
--log-bins                classes are fixed 1-log-unit bins: every order of
                          magnitude (--log-base 10) or every doubling
                          (--log-base 2). Comparable across cases by
                          construction, but sparsely populated bins may be
                          absorbed by the fragment merging step; use
                          --min-zone-frac 0 for strictly pure bins.

Interpreting the heterogeneity metrics (heterogeneity.csv)
----------------------------------------------------------
These answer "are there significant local-vs-global differences (gradients)
in the chosen variable?". With millions of cells classic p-values are
meaningless, so effect sizes are reported instead:

eta2_between_zone         fraction of total variance explained by the zones
                          (ANOVA eta^2). ~1: zones capture real, spatially
                          coherent gradients; ~0: field is essentially
                          homogeneous and the zoning is arbitrary.
zone_contrast             highest zone mean / lowest zone mean. 1 = uniform;
                          >~3 means order-of-magnitude local differences.
cv                        coefficient of variation (std/mean) over fluid cells;
                          classic mixing homogeneity measure (0 = homogeneous).
sigma_log10               spread of log10(values); robust for variables that
                          span decades (EDR, shear).
p05..p99                  volume-weighted percentiles of the variable.
p95_over_p50, p99_over_mean
                          "peakiness": how extreme the top of the distribution
                          is relative to the bulk.
grad_index                mean |grad(var)| * L / mean(var), L = impeller
                          diameter; dimensionless spatial gradient magnitude,
                          comparable across scales/rpm. grad_index_p95 is the
                          95th-percentile equivalent (steep fronts).
significant_gradients     True when eta2 >= --eta2-threshold AND
                          zone_contrast >= --contrast-threshold; the same
                          verdict is printed to the console per case.

Rules of thumb: eta^2 > 0.5 with contrast > 3 indicates process-relevant
gradients (e.g. shear-sensitive material cycling through a hot impeller
zone). Low eta^2 with high CV means variability exists but is spatially
fine-grained rather than organized into distinct regions. Use
exposure_cdf.png to translate this into batch exposure ("x% of the volume
experiences > y"), and profiles.png to locate the gradients (impeller
discharge vs. top-to-bottom stratification).
